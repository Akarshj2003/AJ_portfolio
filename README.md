Tested against real-world visitor telemetry with zero layout clipping:
- **4K Ultra & Large Desktop (`2560×1440` to `1920×1080`)**: Monumental typography and generous negative space.

- **Compact Viewport (`1280×585`)**: Skills section vertically compacted by $170\text{px}$, keeping all 4 bento cards cleanly above the Windows taskbar.
- **Snap / Split-Screen (`725×585`)**: Reflows to single-column without negative coordinate scroll cutoff.

## 🏃 Getting Started Locally

### Prerequisites
- Node.js `18.x` or higher
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Akarshj2003/AJ_portfolio.git

# Navigate into the project directory
cd AJ_portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```
Open [http://localhost:5173/myPortfolio/](http://localhost:5173/myPortfolio/) in your browser.

## 🧪 Automated Testing Suites

# Run the 22-point Multi-Viewport Responsive Matrix assertion suite
